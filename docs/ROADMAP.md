# Production roadmap

## 0.1 — local evidence engine

- Deterministic economics and policy evaluation
- Candidate comparison and demand forecasting
- GitOps/Terraform proposal generation
- Shadow-mode Helm workload
- Reproducible evidence, tests and CI

## 0.2 — observable Kubernetes integration

- Prometheus, OpenCost, OpenTelemetry and DCGM adapters
- vLLM, Triton and NVIDIA NIM metrics
- Grafana dashboards and recording rules
- Versioned JSON Schema and collector fixtures

## 0.3 — Azure implementation

- AKS and Azure Monitor integration
- Azure Cost Management export normalization
- KEDA and GPU node-pool recommendations
- Workload identity, private networking and Key Vault
- Terraform/OpenTofu and Bicep deployment modules

## 0.4 — multi-cloud and hybrid economics

- EKS, GKE and on-premises Kubernetes adapters
- API model-gateway cost and quality benchmarks
- Egress, energy, amortization and capacity-commitment modeling
- Scenario simulation and Monte Carlo sensitivity analysis

## 1.0 — closed-loop controlled optimization

- Signed decision evidence
- Pull-request approval and policy checks
- Canary measurement with predefined abort criteria
- Automatic rollback—not unrestricted autonomous mutation
- Public, versioned evaluation dataset and scorecards
- Measured forecast accuracy and realized savings reporting
